# Stopwatch Project

A simple stopwatch application built with Python and PyQt5.

## Description

This project is a GUI-based stopwatch that allows users to start, stop, and reset time. The time is displayed in the format `HH:MM:SS.CC`.

## Requirements

- Python 3
- PyQt5

## Installation

```bash
pip install PyQt5
```

## Usage

```bash
python stopwatch.py
```
